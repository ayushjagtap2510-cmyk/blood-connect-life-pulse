# Blood Connect – Life Pulse

A web-based Blood Bank Management System developed using Python and Flask. The application helps connect blood donors with people who need blood by providing a platform to register donors, search for available donors, and manage blood requests.

## Features

- **Donor Registration:** Register blood donors with their personal and contact details.
- **Donor Search:** Search for donors based on blood group and location.
- **Blood Requests:** Submit requests for required blood groups.
- **User-Friendly Interface:** Simple and accessible web interface.
- **File Upload Support:** Supports file uploads where applicable in the application.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ayushjagtap2510-cmyk/blood-connect-life-pulse.git
```

### 2. Open the project directory

```bash
cd blood-connect-life-pulse
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```
